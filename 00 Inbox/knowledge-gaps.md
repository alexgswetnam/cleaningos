# Knowledge Gaps

**Where a candidate page goes when you aren't sure it should exist.**

Constitution Rule 2 says default to update. When an agent meets material that might be a
new concept and might belong on a page that already exists, it does **not** resolve the
doubt by creating something. It writes a row here and moves on.

This file replaced the old habit of eager stub creation. A stub is a promise the vault
hasn't kept; a row here is a question someone can answer in thirty seconds.

## How to write an entry

```
### <Candidate name>
**What the material says:** one or two lines
**Source:** the lesson or call, cited at claim granularity
**Might belong on:** [[Existing Page A]], [[Existing Page B]]
**Why it wasn't created:** which of the four creation criteria it fails, or that it's unclear
**Logged:** YYYY-MM-DD by <agent>
```

**The four criteria a new concept must meet — all of them:**

1. Meaningfully distinct from existing knowledge
2. Independently reusable
3. Enough substance to be useful now
4. Likely to be referenced by curriculum, coaching, systems, or marketing

Delete an entry once it's resolved — either the page got created, or the material got
folded into an existing page. Note the resolution in that session's log.
