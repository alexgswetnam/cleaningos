# Rules for `06 Marketing/`

**Assets that promote.** Renderings of knowledge, never the source of it.

## Write from concept pages, not transcripts

A YouTube video, a VSL, a lesson, an email, and an objection answered on a sales call are
five presentations of the same knowledge. Read the canonical concept page and render it.

If you're pulling a fact from a transcript that isn't on the concept page, **the concept
page is incomplete.** Update it first.

## The gates, before you write a word

1. **Contested check** — any concept with `contested: true` or a `> [!warning] Contested`
   callout covering the claim: **stop and ask.** Do not pick a side, do not write around it
   with vague phrasing
2. **Superseded check** — make sure you're using the current claim, not the one in the
   collapsed history. Easy to miss when skimming
3. **Claim register check** — every factual claim, price, guarantee, statistic or named
   student must have a usable status in `07 Company/Claim Register.md`

## Facts get verified against raw sources

For proof, exact quotations, results or numbers: verify against the original source
material in `01 Sources/`. **Never against an AI-generated summary** — not the files in
`09 Derived/`, not the lesson `.md` files inside course folders.

Then update the relevant concept page or proof record, so the next person doesn't repeat
the work.

## Voice

`Voice/Alex Voice.md` — the anchors are real Alex sentences. **Imitate those, not a
description of them.** Check the Voice Log for rules from past corrections.

Every "Harvest" that means the product is written "Harvest CRM."

## Frontmatter

`renders:` `shipped:` `channel:` `live:` — all four, every time.
