# Rules for `01 Sources/`

**Immutable. Permanently.** No edits, no reformatting, no cleaning up, no deletions.

The only permitted write is **adding a new file**.

If a transcript is garbled or a source is wrong, note that on the concept page citing it.
The source stays as it is. It is the evidentiary record.

## Being in this folder does not make a file evidence

| File | What it is |
|---|---|
| `*-RAW.txt`, lesson `.txt` | **Evidence.** What was actually said |
| Source-record wrappers (`2026-04-01 Weekly Coaching Call.md`) | **Provenance.** Origin, date, participants, artifacts. Also fine here |
| Lesson `.md` inside course folders | **AI-generated summaries. Derived, not evidence** — 171 of them, catalogued in `09 Derived/Derived Source Manifest.md` |

**A factual claim — a number, quotation, student result, price, date — is verified against
the raw `.txt`, never against a summary.** Summaries paraphrase and compress; any of that
can quietly change a fact.

## Citation granularity

| The claim is… | Cite |
|---|---|
| Background, or restates what the page already said | the course — `Labor 101` |
| A number, script, policy, date, or anything contested | the lesson — `Labor 101 → Determining Cleaners' Pay` |

**The test: if Alex challenged this line, could you find the evidence in under a minute?**

## Filenames

Sources keep their original names. When a page in `03–07` collides with a source filename,
**the page gets renamed** — never the source.
