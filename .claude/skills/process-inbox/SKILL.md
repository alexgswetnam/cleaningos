# Process Inbox

Work `00 Inbox/`. Skip `canon-proposals.md`, `review-queue.md`, `knowledge-gaps.md`,
`ingest-run.md` — those are queues, not arrivals.

## Classify each item

| Kind | Action |
|---|---|
| **Voice note / raw thought** | Extract the ideas, run the ingest search step, update or create. Mark Alex's own claims as his |
| **Raw material** | Move to `01 Sources/`, then ingest fully |
| **Question** | Add to the concept's FAQ, **unanswered.** Do not answer from your own knowledge — this vault holds what Alex teaches, not what you know |
| **Canon change** | Write to `canon-proposals.md`. Never edit `02 Canon/` |
| **Product fact** | `05 Products/` **and** a row in `07 Company/Claim Register.md` |
| **Task / reminder** | Leave in place, flag in the report. This is not a to-do list |
| **Junk** | Move to `99 Scratchpad/` |
| **Ambiguous** | Leave it. Ask |

## Mark provenance

Alex's unsourced thinking is a different epistemic category from something taught on a
recorded call:

```markdown
> [!note] Alex — YYYY-MM-DD, from inbox
> The claim, in his words.
```

In six months an agent writing a VSL needs to know which claims have been tested with
students and which were a shower thought.

## Clean up

Remove from `00 Inbox/` only after the content is verifiably written elsewhere. **When in
doubt, leave it.**

## Report

Per item: what it was, where it went, what it connected to. Then what you left behind and
why.
