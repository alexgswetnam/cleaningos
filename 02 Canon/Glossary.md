# Glossary

Terms with their own page link there rather than being defined twice — this page is an
index, not a second home for definitions.

| Term | Definition |
|---|---|
| **CleaningOS** | The whole method. The operating system underneath the tactics. |
| **Engine** | One of four core business areas. See [[Four Engines]]. |
| **Season** | The stage an Engine is in. See [[Four Seasons]]. |
| **Law** | One of five governing principles. See [[Five Laws]]. |
| **Harvest** | The fourth Season. **Bare "Harvest" always means the Season.** |
| **Harvest CRM** | The software. Always both words, never shortened. |
| **Owner** | The cleaning business owner. Our student. |
| **Client** | The owner's customer — whose space gets cleaned. |
| **Cleaner** | The person doing the work. |
| **One Step** | The single next action, given the owner's Season. |
| **Business GPS** | The diagnostic that locates an owner and names their one step. |
| **Constraint** | The Engine currently limiting the whole system. |
| **Canon** | The IP in `02 Canon/`. Edited by Alex only. |
