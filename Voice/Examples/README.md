# Voice Examples

**Examples Alex has explicitly approved as good representations of the voice.**

Nothing goes in this folder unless Alex has said it's right.

## What these are for

**Calibration material — not templates.**

Read them before writing to tune the sound. **Do not copy them word-for-word.** A phrase
lifted from an approved example and pasted into new copy is plagiarism of ourselves, and
it produces writing that sounds assembled rather than said.

The test: read an example, then read your draft. Same person?

## Why this folder is empty

Because inventing examples would defeat the point. An example Claude wrote and Alex never
approved is not calibration — it's a machine grading its own homework.

`Voice/Alex Voice.md` records the same gap in its Confidence table: written voice, marketing
copy and short-form social are all **Unknown**, because there are no samples.

## Files worth adding, when real ones exist

- `Great VSL Section.md`
- `Great YouTube Intro.md`
- `Great Email.md`
- `Great Community Post.md`
- `Great Coaching Explanation.md`

## How to add one

1. Alex points at something real — a post that performed, an email he wrote, a section he
   liked.
2. Save it verbatim. Note the channel and the date.
3. One line on **why it's good** — what specifically to copy. "Good email" teaches nothing;
   "opens with the reader's problem in their words, no setup" teaches something.
4. If it's a correction of something Claude drafted, run `/voice` as well — the diff
   belongs in the Voice Log.
