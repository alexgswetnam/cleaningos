# 08 Logs

Session records written by `/save`. Read by `/resume`.

These are **not knowledge**. They record what was done to the vault and when — nothing
here defines an idea, and no concept page should ever link to a log. If a log contains a
fact worth keeping, that fact belongs on a concept page in `03 Concepts/`; the log only
notes that it was put there.

Constitution §V has no row for this folder because logs are outside the knowledge
hierarchy entirely, the same way `99 Scratchpad/` is. The difference: scratchpad is junk
you'd never miss, logs are an audit trail you would.

One file per session: `YYYY-MM-DD-short-description.md`.
