# Every SOP We Use

32 operational SOP lessons covering the day-to-day running of the cleaning business:
client-facing scripts (cancellations, re-cleans, lockouts, bad reviews, payment
failures), cleaner-facing docs (pay, schedule, supplies, picture guidelines), sales
and pipeline management (GHL stages, sales call outline, pricing), marketing routines
(GBP posting, review requests), and admin/ops cadence (daily checklist, EOW/Friday,
holidays, slow-week time management, database reactivation).
