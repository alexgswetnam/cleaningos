Quick Summary
Set a correct default availability as your baseline. Update specific dates weekly—ideally on Fridays—and give at least one week’s notice for changes. Avoid changing availability within 72 hours of scheduled cleans unless it’s an emergency; notify the team immediately if so. Accurate inputs keep operations smooth and professional.

Core Teaching
Default availability is the foundation; weekly updates keep it real. Advance notice protects clients, routes, and teammates.

Key Principles
Maintain accurate default availability.
Update weekly with sufficient notice.
Minimize late changes; communicate emergencies fast.
Step-by-Step Process
Set Default Availability
Booking Koala: Menu → Manage Availability → Change Availability → Default Availability; enter consistent days/times.
Update Weekly Availability
Manage Availability → Change Availability → Specific Date; adjust for added time or time-off; notify team for significant time off.
Best Practices
Update Fridays; avoid changes within 72 hours; aim for one week’s notice.
