Quick Summary
Don’t finalize cancellations by default. Review the account, then call briefly to understand the reason and offer easy rescheduling options. Keep it helpful, professional, and low-pressure. If they reschedule, confirm and update systems; if they cancel, process per policy and leave the door open. If no answer, leave voicemail and follow with a text.

Core Teaching
Calls outperform texts for saving appointments. Offer flexible options, focus on convenience, and protect the relationship.

Key Principles
Helpful, not pushy.
Phone first when possible.
Offer simple alternatives; make rescheduling easy.
Step-by-Step Process
Receive Request
Don’t cancel immediately; gather client history, frequency, preferred cleaner, availability, issues, and policy status.
Call the Client
Goals: rapport, reason, alternatives, preserve booking.
Use discovery questions; offer new dates/times; mention preferred cleaner when relevant.
If Rescheduled
Confirm new date/time; update system; notify cleaner if needed; send confirmation.
If Still Cancels
Acknowledge; process per policy; leave door open.
If No Answer
Voicemail + follow-up text; await response if timing allows.
Rules
Do: helpful, professional, confident; don’t: pressure or delay excessively.
Scripts, Examples, or Phrases to Keep
“I saw your message… wanted to quickly check in before we finalized any changes.”
“Would another day work better for you?”
“We do have some alternative openings available if rescheduling would help.”
Common Mistakes / Warnings
Handling entirely by text.
Sounding salesy or argumentative.
Delaying confirmed cancellations too long.
