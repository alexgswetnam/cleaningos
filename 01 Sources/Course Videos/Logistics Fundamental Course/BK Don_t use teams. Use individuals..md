## Quick Summary
This lesson is a quick Booking Koala tip. The speaker saw someone using teams and says it was messing them up. Instead, they recommend setting up individual providers and then pairing individuals together as needed. This makes it easier to check availability by clicking each provider. The lesson also points out that Booking Koala has different calendar views, and using the wrong view can make everything feel more difficult. The speaker prefers week view and timeline view. The lesson is not a full systems training; it is a practical setup correction.
## Core Teaching
The core teaching is simple: in Booking Koala, avoid using teams if it makes scheduling harder. Set up individual cleaners as providers, then pair individuals together for jobs when needed.

This makes availability easier to see because the user can check each provider directly. It also avoids confusion that can happen when teams are treated as the main scheduling unit.

The lesson also reminds students that the calendar/dashboard view matters. A difficult view can make Booking Koala feel harder than it is. The speaker prefers week view and timeline view because they make the schedule easier to understand.
## Key Principles
- Use individual providers instead of teams when teams create confusion.
- Pair individuals together as needed.
- Check availability by provider.
- Calendar view affects how easy the system feels.
- Week view and timeline view can make scheduling clearer.
## Step-by-Step Process
1. Open Booking Koala provider setup.
2. Set cleaners as individual providers.
3. Pair individual providers on jobs instead of creating rigid teams.
4. Use provider availability to check who can take a job.
5. Test different calendar/dashboard views.
6. Use week view or timeline view if it makes scheduling clearer.
